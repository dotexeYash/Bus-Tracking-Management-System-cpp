#  Bus Tracking and Management System

A beginner-friendly C++ project designed to simplify bus management operations at a depot.

##  About the Project

The Bus Tracking and Management System helps depot managers maintain bus records, assign routes, manage driver and conductor details, update bus positions and identify buses travelling too close to each other.

##  Features

- Add and manage buses.
- Assign routes and schedules.
- Store driver and conductor IDs.
- Track and update bus positions.
- Generate alerts when two buses on the same route are within 2 km.
- View buses belonging to a particular depot.
- Delete bus records.

##  How to Run

Compile the program:

```bash
g++ BusTrackingSystem.cpp -o bus
```

Run on Windows:

```bash
.\bus.exe
```

##  Limitations

- Bus positions are updated manually.
- GPS-based real-time tracking is not implemented.
- Bus information is stored in an array and is not permanently saved.
